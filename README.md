# The AI Agent Apology One-Liner

A program that writes the funniest single line an AI agent sends its human
right after it accidentally deleted a file, pushed to main, and emailed the
boss.

`main.py` (Python 3.13, stdlib only, deterministic, offline) writes the line
to `/output/entry.txt`.
